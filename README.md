# Thejas Gowda — Personal Portfolio (Midnight Frosted Glass)

A live 3D-motion, frosted-glass personal portfolio built for **Thejas Gowda** (`github.com/TeJAS512-MAX`) with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

## Customization

All editable personal info, links, repositories, technical skills, and tools live in [`src/data/portfolio.ts`](src/data/portfolio.ts):

- `PERSONAL_INFO`: Name, university/role bio, GitHub/LinkedIn/Discord links, email, highlights, and hero/studio images (`public/images/`).
- `PROJECTS`: Six projects & showcases sourced from `github.com/TeJAS512-MAX` (*FoodBridge*, *Northstar Audit Agent*, *Deepfake Image Classifier*, *Side Agents Forensics App*, *Visual Identity & Branding*, *Prompt & RAG Architecture*).
- `SERVICES`, `TECHNICAL_SKILLS`, & `TOOLS`: Core services/collaboration rows, technical focus bars, and the **MY ARSENAL.** stack strip.
